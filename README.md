# Digital Forensics Investigation Prototype

## Overview
This project is a modular digital forensics investigation tool developed for digital forensic investigators. 

## Features 
- File Hashing (MD5, SHA256)
- Hash comparison
- EXIF metadata extraction
- Timeline generation (CSV, JSON, SQLite)
- Keyword and regex search
- GPX movement reconstruction
- Audit logging
- Report Generation

## How to Run
Run python main.py
